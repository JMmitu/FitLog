# FitLog — Workout Library

## Project Description

FitLog is a modern and responsive workout library web application designed to help users explore workouts, create a daily workout plan, save exercises for later, and track their workout progress. The application provides a clean dark-themed interface with workout details, useful statistics, sorting options, and responsive design for mobile, tablet, and desktop devices.

## Technologies Used

- Next.js
- React
- JavaScript (ES6+)
- Next.js App Router
- Tailwind CSS
- Lucide React
- REST API
- LocalStorage
- Git & GitHub

## Key Features

1. **Workout Library**
   - Browse workouts with images, categories, equipment, duration, calories, and ratings.

2. **Workout Details**
   - View complete workout information including difficulty, sets, reps, instructions, and specifications.

3. **Today's Plan**
   - Add workouts to today's plan with a maximum limit of five exercises.

4. **Saved Workouts**
   - Save workouts for later and access them from the Saved tab.

5. **Workout Tracking**
   - Mark workouts as completed, remove workouts, view live exercise statistics, and track total minutes and calories.

## Additional Features

- Responsive design for mobile, tablet, and desktop
- Workout sorting by duration, calories, and rating
- Toast notifications
- Loading states
- Empty states
- Custom 404 page
- LocalStorage persistence
- Dynamic workout detail routes
